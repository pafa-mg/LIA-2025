## Personal Letter

### It Always Starts with a Snake 🐍
The quote above took me some time to fully understand, but nowadays it has become a daily part of my coding experience. I discovered the joys of coding during my bachelor's degree in Molecular Biology. Like many others, my first introduction to this world was through the programming language Python (version 2.6).
I was immediately hooked on how fast and direct the feedback loop was, especially in contrast to world of biology, where experiments could take a month or more to yield a meaningful result. 

These experiences, combined with my intrinsic drive to keep learning and my need for a creative outlet in a real-world setting led me to apply to the Java Program at IT Högskolan. 

### Coffee and Code are Always Being Ground to Perfection In Increments ☕
As the title implies, every line of code needs to be processed, maintained and improved whether by a developer, a team or another entity. 
This mindset has influenced my strive for clean code practices and continuous improvement in my growth as a software engineer.  

My goals in applying for this internship are to:

 * Learn new strategies to avoid contributing to technical debt.
 * Develop new technical skills to further improve both the product and my personal growth as a developer.
 * Build a solid foundation of experience in maintaining and delivering software as a product.
